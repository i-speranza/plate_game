# Changelog

Main updates to Plate Word Game, grouped by date.

## 2026-07-30

- Answer input is focused automatically when a round starts, so you can type immediately without clicking the text box

## 2026-07-27

- Host can choose 3–6 letters per round in the lobby (default 4); all rounds in a match use the same count
- Updated scoring bands and ordered-match bonus to scale with letter count
- Letter highlights on submit and confetti when all plate letters match in order
- Extended Italian dictionary
- Improved graphics
- Added possibility to display a valid solution after each round
